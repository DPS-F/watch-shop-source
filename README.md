*(Загружаются товары из категории часов, очков и украшений)*

## Команды для запуска
Для работы с проектом должен быть установлен Node.js.

1. Установка зависимостей:
   `npm install`
2. Запуск сервера для разработки (с автообновлением):
   `npm run dev`
3. Сборка проекта для публикации:
   `npm run build`
4. Локальный просмотр готовой сборки:
   `npm run preview`
